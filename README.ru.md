# CapsSwitch

Русский | [English](README.md)

<img src="assets/CapsSwitch.png" alt="Иконка CapsSwitch" width="96">

Переключение раскладки Windows клавишей **Caps Lock**, как при **Win + Пробел**.
CapsSwitch работает в трее, не записывает ввод и не использует сеть.
При русском языке интерфейса Windows меню на русском, иначе — на английском.

## Запуск

Нужны Windows 10/11 и хотя бы две раскладки. Дополнительная среда выполнения не нужна.

**Установщик.** Скачайте `CapsSwitch-…-windows-setup.exe` из раздела **Releases** и запустите.
По умолчанию он ставит программу для текущего пользователя без прав администратора;
можно выбрать установку для всех пользователей в Program Files. Установщик может
включить запуск при входе в Windows и добавляет ярлык в «Пуск»; удаление — через **Параметры → Приложения**.

**Переносная версия.** Скачайте ZIP для **x64** или **ARM64**, распакуйте и запустите `CapsSwitch.exe`.
Для запуска при входе в Windows добавьте ярлык EXE в `shell:startup` (Win + R).
Перед переносом или удалением программы удалите этот ярлык.

## Управление

| Действие | Результат |
| --- | --- |
| Caps Lock | Следующая раскладка, один раз за нажатие |
| Shift + Caps Lock | Обычный Caps Lock |
| Caps Lock с Ctrl, Alt или Win | Стандартное поведение клавиши |
| Правый щелчок по значку трея | Пауза, сведения о программе, выход |
| Двойной щелчок по значку трея | Пауза или продолжение |

На паузе Caps Lock работает как обычно. В сеансе Windows запускается один экземпляр.
Перед обновлением или удалением EXE выберите **Выход** или выполните `CapsSwitch.exe --stop`.
Для окон администратора могут понадобиться такие же права у CapsSwitch.
Экран входа и защищённый экран UAC не поддерживаются.

## Сборка

Нужны PowerShell и Visual Studio Build Tools 2022 с компонентами C++,
Windows SDK и инструментами ARM64 для сборки под ARM64. Для установщика нужен Inno Setup 6
(`winget install JRSoftware.InnoSetup`); он собирается только при сборке обеих архитектур.

```powershell
.\build.ps1 build                 # bin/x64 и bin/arm64
.\build.ps1 test                  # проверки x64
.\build.ps1 package               # сборка, тесты, ZIP, установщик и SHA-256 в dist/
.\build.ps1 package -Arch x64      # только x64
```

GitHub Actions выполняет ту же команду упаковки. Тесты проверяют состояние клавиш,
значки трея и жизненный цикл обработчика; переключение раскладки проверяется в сеансе Windows.
[Архитектура](docs/architecture.md).
