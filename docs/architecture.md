# Архитектура

- **C17 и Win32 без CRT.** Один переносимый EXE без дополнительной среды выполнения;
  собственная точка входа позволяет обойтись системными библиотеками Windows.
- **Обработчик клавиатуры в отдельном потоке.** Медленная работа меню не задерживает
  `WH_KEYBOARD_LL`; обработчик передаёт запрос переключения оконному потоку.
- **Переключение через Win + Пробел.** `SendInput` использует штатный порядок раскладок
  Windows. Собственные события помечены, чтобы обработчик их пропускал.
- **Режим нажатия фиксируется до отпускания.** Это исключает автоповторы и смешение
  подавленных и обычных событий при смене паузы или модификаторов.
- **Модификаторы сверяются с физическим состоянием.** Отпускания на защищённом
  рабочем столе не доходят до обработчика; сверка предотвращает залипание.
- **Отложенное переключение.** Пока удерживается модификатор, отправка ждёт до двух
  секунд, чтобы не отпускать физические клавиши пользователя.
- **Скрытое окно верхнего уровня.** Оно получает события перезапуска Explorer,
  смены темы и DPI; message-only окно не получает нужные широковещательные события.
- **Иконка из ресурсов по DPI панели задач.** При ошибке загрузки используется
  системный глиф глобуса; на паузе значок приглушён.
- **Mutex и событие остановки в пределах сеанса.** Исключают второй экземпляр;
  `--stop` ждёт завершения, чтобы EXE можно было заменить.
- **Установщик Inno Setup поверх переносимого EXE.** Приложение не копирует себя и не
  пишет автозагрузку: это делает установщик, удаление идёт через «Приложения». По умолчанию
  установка для пользователя без UAC; Program Files не даёт преимуществ, пока EXE не
  подписан (`uiAccess` требует подписи). Один установщик содержит x64 и ARM64.
